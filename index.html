The Writing Room

A little room for Tibetan.

Type EWTS and watch Tibetan appear. Highlighted text is still settling and becomes fixed when you press space or Enter.

Editor

Limits. EWTS typing works at the end of the text. If you move the cursor into earlier text, typing there is ordinary browser editing. Backspace removes the last typed letter of the highlighted run, then behaves normally. Phone keyboards that use composition may bypass EWTS typing. This is not an IME, and has no dictionary or suggestions.

Symbols

Draft catalogue. The sequences are checked against the engine; the labels have not been reviewed by a Tibetologist. Choose a symbol to insert it where the cursor is, or copy it.

    Examples

    Each button replaces the text with a sample. The last group shows unsettled questions that a specialist should judge.

      Advanced

      Writes a few Tibetan letters as single precomposed characters (for example U+0F43). The result is not NFC. Text already fixed is kept as it is; only the highlighted run is re-read in the new mode.

      Report a problem

      Nothing is sent from this page. Review the text, then either copy it or open a pre-filled issue on GitHub, where you will see it before you submit. Issues on this repository are public, so untick the text box below if the text is private.
