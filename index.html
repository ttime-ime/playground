The Writing Room

A little room for Tibetan.

Type EWTS and watch Tibetan appear. Highlighted text is still settling and becomes fixed when you press space or Enter.

Editor

Latin

Type ordinary Latin text in the middle of Tibetan: nothing is converted and the space bar is a space. Switch with Alt+Shift+L while the page is focused. Switching on fixes the highlighted Tibetan first, so nothing typed is lost; switching off starts a fresh Tibetan run. This is a first version for testing: the shortcut and the switching rule are open questions, so tell us what works for you.

In Latin mode, type ; and then a key for an IAST letter, or : and then the key for the capital. A ; or : not followed by one of these keys stays as typed, so ordinary punctuation is unaffected; type it twice for a single literal one before a letter. Backspace removes a waiting ; or :. Which keys feel natural, and whether ; and : get in your way, are what we want to learn.

        Writes a few Tibetan letters as single precomposed characters (for example U+0F43). The result is not NFC. Text already fixed is kept as it is; only the highlighted run is re-read in the new mode.
